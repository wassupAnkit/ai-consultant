# F. Post-study work and migration

This domain holds everything a counsellor needs to answer "what happens after I graduate": the post-study work (PSW) visa of each of the ten destinations, the points tests and Express Entry factors that turn a qualification into permanent residence, state and provincial nomination, regional and employer-sponsored routes, job-seeker permits, typical time-to-PR and citizenship, and the policy change log that governs all of it. Student-visa rules (work hours while studying, financial proof, conditions) live in `destination-visa.md`; occupation lists, skills assessment and labour-market data live in `occupation-career.md`; profession registration lives in `regulated-professions.md`. Every row here is `quotable = disclaimer` unless it is an internal observation: Edge may state the fact but must attach the general-information / registered-migration-adviser disclaimer, because only MARA (AU), RCIC (CA), IAA (UK, formerly OISC), IAA (NZ) licensees may give immigration advice. Facts that change by ministerial instrument (fees, thresholds, list membership, cut-offs) are marked `on_policy_change` or `live_fetch` and must carry `valid_from` / `valid_to` provenance; where the authoritative page is on an allow-listed government host, `today_field_path` says `missing (live fetch only)` because Edge can read it at answer time but does not store it. Values in `possible_values` are worked examples current to the 2025–26 program year and must be re-verified before being surfaced.
