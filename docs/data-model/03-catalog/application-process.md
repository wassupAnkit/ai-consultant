# K. Application process

This domain covers *how* a student gets from "I want this course" to a valid enrolment
document (CoE / CAS / I-20 / LOA / Zulassung / EMGS VAL / NZ offer of place): the channel
the application travels through, every document the institution or the visa authority asks
for and at which stage, statements and references, interviews, credential evaluation,
acceptance steps, deadline mechanics, status vocabulary and the payment *process* from each
origin country. Institution-level *policies* (application fee and waiver, offer types and
validity, deposit amount, refund schedule, deferral, release letter) live in
`institution.md`; the amounts of visa-side fees live in `destination-visa.md`; the money
side of payments, refunds and remittance limits lives in `fees-and-money.md`. Rows here
frequently vary by `nationality`, `level` and `applicant_type`, and the `DocumentRequirement`
rows are keyed per (institution or visa) × level × nationality × stage so a counsellor gets
one checklist per student, not a page of prose.
