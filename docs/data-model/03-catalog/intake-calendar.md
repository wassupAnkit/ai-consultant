# T. Intake calendar

The Intake Calendar domain holds every dated event a counsellor needs to plan a student's application backwards from a start date: when applications open and close, when the deposit and scholarship deadlines fall, the last day a CoE / CAS / I-20 can be issued, the recommended visa-lodgement date, orientation, census, exam and break periods, graduation, latest arrival and institution shutdowns, plus the live status of each intake (open, closing, full, waitlisted, capped) with an as-of stamp. It answers the S19 time-sensitive questions ("Can I still make February?", "When is the last date to pay the deposit?", "If I lodge the visa in November will it be granted in time?") and the S11 / S13 questions about what the year looks like once the student lands. The main entity is `IntakeCalendar` keyed by offering or institution plus term; a few rows sit on `Institution`, `Destination`, `Region`, `SourceCountry` (origin holidays) and `Agency` (Expert Education events). Deadline *policies* (rolling admission, deferral rules, deposit refundability) live in domains B and K; this domain records the concrete dates each cycle.
