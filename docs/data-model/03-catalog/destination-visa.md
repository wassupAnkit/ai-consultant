# E. Destination visa

This domain holds everything a counsellor needs to answer "can this student get the visa, what will it cost, how long will it take, what must they show, and what can they do once they hold it" for each of the ten destinations (AU, CA, GB, NZ, US, DE, IE, MY, AE, TH). Almost every value here varies by the student's nationality, study level, applicant type (onshore/offshore) or, for Canada, province, so the `variant_axes` column is load-bearing: storage keys each value on those axes and the answer layer picks the variant that matches the student in front of the counsellor. Post-study and graduate visas, PR points and skilled lists live in `post-study-migration.md`; institution and non-visa fees live in `fees-and-money.md` (visa, biometrics, medical, insurance, SEVIS, IHS and registration fees are catalogued here as `FeeItem` rows); the test catalog lives in `english-and-tests.md` (the visa-side English rule is here); city living-cost figures live in `city-cost-of-living.md` (the official figure the visa formula uses is here). Nothing in this domain is stored today: Edge answers visa questions only by live-fetching official pages in `WEB_FETCH_ALLOWED_DOMAINS` through a 6-hour cache, so `today_field_path` is `missing` everywhere and `missing (live fetch only)` where a live fetch currently substitutes. Every row is `disclaimer` (general information, not migration advice) unless it is an internal observation, which is `internal` and never quoted to students.
